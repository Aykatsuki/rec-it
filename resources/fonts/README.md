# Caption fonts

Bundled for captions (ADR-011, ADR-032). The same files are given to libass in the preview
(JASSUB) and in the export (FFmpeg `ass` filter), so text looks identical in both.

All are licensed under the SIL Open Font License 1.1 (licence texts alongside):

| File | Family | Source |
|------|--------|--------|
| Montserrat-ExtraBold.ttf, Montserrat-Black.ttf | Montserrat | github.com/JulietaUla/Montserrat |
| Poppins-Bold.ttf, Poppins-SemiBold.ttf | Poppins | github.com/google/fonts (ofl/poppins) |
| Anton-Regular.ttf | Anton | github.com/google/fonts (ofl/anton) |
| BebasNeue-Regular.ttf | Bebas Neue | github.com/google/fonts (ofl/bebasneue) |
